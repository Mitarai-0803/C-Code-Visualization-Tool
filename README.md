# C-Code-Visualization-Tool

> C++のファイルの動きを可視化できるツール

C++コード可視化ツールです。自分がコードを理解するのにGUI的な方がわかりやすいかつ、楽しく確認をしたいと思い、制作しました。

対応しているファイルはDXライブラリやDx11を使ったファイル群です。

変数の動きやどこに値を持って行ってどこの関数に接続したかなどが順番に見られます。

https://mitarai-0803.github.io/C-Code-Visualization-Tool/

## 特徴

- 文字を見るのに疲れた・内容を理解するのが難しい人向け
- ファイルを入れるだけでクラス図なども確認できる
